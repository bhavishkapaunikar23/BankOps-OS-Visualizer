THEORY

Race conditions & mutual exclusion

Two ATM requests that read and write a shared balance can lose an update when their critical sections overlap. A mutex serializes access; a semaphore models permission to enter the critical section.

Banking example: two fictional withdrawals compete for one shared account balance. This browser demonstration does not access real accounts.

PROCESS STATES

State transitions & context switching

New processes enter Ready, receive CPU time in Running, may block while waiting for I/O, and eventually terminate.

New→Ready→Running→Terminated
Running ↔ Waiting / Blocked ↔ Ready

Run the trace to see context switches between banking processes.

DEADLOCK DETECTION

Allocation and outstanding requests

Enter matrices as rows separated by semicolons and values separated by commas. The detector uses the multiple-instance matrix algorithm; a graph cycle is only sufficient evidence under single-instance assumptions.
